# BookStoreApp — Информационная система книжного магазина

Это учебный проект — автоматизированная система учёта товаров, продаж и клиентов для розничного книжного магазина. Сделана на C# с использованием Windows Forms и базы данных Microsoft SQL Server.

## Что умеет система

В системе есть авторизация с тремя ролями. Администратор может всё: добавлять и редактировать книги, управлять клиентами и поставщиками, оформлять и отменять заказы, делать приход товара и смотреть отчёты. Продавец может только искать книги, оформлять заказы и отменять их. Бухгалтер видит только отчёты.

Пароли хранятся в базе в виде хеша SHA256. Все SQL-запросы параметризованные, чтобы не было инъекций.

Оформление заказа работает через корзину. Выбираешь книгу, указываешь количество, добавляешь в корзину, потом выбираешь клиента или оформляешь как гостя, выбираешь способ оплаты и нажимаешь «Оформить». Остатки книг списываются автоматически, всё происходит в транзакции. Отмена заказа возвращает книги на склад.

Приход товара работает в два этапа. Сначала создаётся заявка поставщику — остатки ещё не меняются. Потом в отдельной форме заявку можно подтвердить, и только тогда книги добавляются на склад.

Отчёты есть по остаткам книг, продажам по дням, статистике клиентов, списку сотрудников и поставщиков. Любой отчёт можно выгрузить в Excel или отправить на печать.

## Стек технологий

C#, .NET Framework 4.7.2, Windows Forms, Microsoft SQL Server, ADO.NET, EPPlus для работы с Excel, System.Net.Mail для отправки email.

## Как запустить

Нужно восстановить базу данных из файла BookStore.bak или выполнить скрипт BookStore.sql. Потом настроить строку подключения в App.config под свой SQL Server, восстановить NuGet-пакеты и собрать решение в Visual Studio.

В App.config строка подключения выглядит так:

    Data Source=.\SQLEXPRESS;Initial Catalog=BookStore;Integrated Security=True

Замени `.\SQLEXPRESS` на имя своего сервера, если оно другое.
